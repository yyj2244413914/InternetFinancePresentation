# 中小企业经营信贷的监管剖析 · 放映说明（README）

## 一、怎么打开

1. 确保本文件夹里有**两个东西**在一起：
   - `汇报_中小企业经营信贷的监管剖析.slides.html`
   - `slides_assets\`（6 个文件，缺了会白屏）
2. **双击** `汇报_中小企业经营信贷的监管剖析.slides.html`，用浏览器打开（Edge / Chrome 均可）。

> - ❌ 不要用 JupyterLab / VS Code 预览打开（会白屏），要用**浏览器**；
> - ✅ 不需要联网、不需要 Python/Jupyter，任何 Windows 电脑都能放。

## 二、怎么操作

### 翻页
| 操作 | 效果 |
|---|---|
| `←` / `→` 键 | 上一页 / 下一页 |
| 空格 | 下一页 |
| 鼠标滚轮 / 触控板滑动 | 先滚动当前页内容，**滚到底自动翻页**（智能滚动，不会乱跳） |

### 右下角控制条
| 按钮 | 作用 |
|---|---|
| `⏮` `⏭` | 上一页 / 下一页 |
| `▦ 总览` | 缩略图总览，点任意页跳转 |
| `⛶ 全屏` | 进入 / 退出全屏 |
| `A−` / `A+` | 缩小 / 放大字号 |
| `代码` | 显示 / 隐藏代码（默认只显示结果，放映建议保持隐藏） |
| 页码 | 当前页 / 总页数 |
| `✕` | 收起控制条 |

### 常用快捷键
| 键 | 作用 |
|---|---|
| `F` | 全屏 |
| `Esc` 或 `O` | 总览（缩略图） |
| `S` | 演讲者备注（如有） |

## 三、常见问题

| 问题 | 原因 / 解决 |
|---|---|
| 打开是白屏 | 只拷了 html、没拷 `slides_assets\` → 整个文件夹一起拷 |
| 页面突然跳页 | 滚动到底会翻页（这是智能滚动）；想精确控制用 `←`/`→` 或 `⏮ ⏭` |
| 字太小 / 太大 | 右下角 `A+` / `A−` 调字号 |
| 想给别人演示 | 把**整个文件夹**（html + slides_assets）拷到 U 盘，对方双击 html 即可 |

## 四、内容速览（共 4 部分）

1. **引言**：中小企业的地位与融资困境；
2. **中小企业信贷监管流程**：贷前调查 → 贷款审批 → 贷款发放 → 贷后管理；
3. **风险评估**：方法回顾 + 项目示例（爬取数据 → 大模型 NLP → 可视化 → XGBoost 建模，AUC≈0.96）；
4. **结论**：中小企业信贷风险的第一信号是"盈利与现金流的脆弱"，而不是规模。
