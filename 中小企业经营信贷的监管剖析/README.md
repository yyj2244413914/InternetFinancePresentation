## 研究对象是「中小企业」，不是「中小银行」

这是一个必须说清楚的口径问题：**监管处罚的开具对象只能是银行**，如果只用处罚数据，
研究对象会不知不觉从"中小企业"漂移成"中小银行"。因此本项目的证据分成**两层**：

| 证据层 | 回答什么 | 数据 | 规模 |
|---|---|---|---|
| **企业侧**（需求方） | 中小企业长什么样？谁会陷入困境？能否事前识别？ | 新三板/北交所财务面板 | **679 家 × 3,381 企业-年** |
| **监管侧**（供给方） | 银行为中小企业放贷时，实际出了什么问题？ | **SME 专项处罚**（事由里明确出现 小微/普惠/个体工商户/涉农/经营贷/支农支小 等表述，且与信贷相关） | **745 条**（占全部 37,236 条的 2.0%） |

全量 3.7 万条处罚只作为**背景分母**，用于对照"SME 专项 vs 全部信贷处罚"的结构差异；
"中小银行"仅作为**放贷方分类的一个维度**，不是研究对象。

### 两层证据的关键发现

**企业侧**（困境组 vs 健康组，中位数）

| 指标 | 健康企业 | 困境企业 | p 值 |
|---|---|---|---|
| 销售净利率 | **6.69%** | **−8.87%** | 2e−208 |
| 加权 ROE | 8.34% | −7.12% | 2e−197 |
| 利息保障倍数 | 9.42 | **−3.62** | 4e−158 |
| 经营现金流/总负债 | 0.12 | 0.01 | 6e−59 |
| Altman Z′ | 2.57 | 1.51 | 1e−56 |

→ **中小企业陷入困境的核心是盈利与现金流的脆弱，而不是规模。**
样本总资产中位数 1.92 亿元、营收 1.09 亿元、资产负债率 41.0%、困境率 **38.7%**。

**监管侧**（SME 专项 745 条）

| 结论 | 数据 |
|---|---|
| 违规集中在「过程」 | 贷款三查不到位 **288 条（43.6%）** |
| 放贷方以中小机构为主 | 农村中小银行+村镇银行+城商行 **335 条（59.4%）** |
| 与全部信贷处罚相比**资金挪用更突出** | 14.5% vs 10.6%（**+3.9pp**） |
| 损失量级 | 单笔中位数 **71 万元**、合计罚没 **12.76 亿元**、99.9% VaR **7.82 亿元/年** |
| 一类"只有中小企业信贷才有"的违规 | **小微企业划型不准确：29 条、24 家、罚没 3.96 亿元** |

<div style="padding:0"></div>

> **"小微企业划型不准确"值得单独说**：银行为了完成小微/普惠考核指标（"两增两控"），
> 把不符合划型标准的企业统计成小微企业。这类违规不伤害单笔贷款，
> 但让"中小企业贷款余额"这个监管指标本身失真 —— 是对监管信息基础的破坏。

## 二、核心结论（可直接引用）

1. **信贷类违规占银行处罚的主体**：贷款三查不到位、违规发放贷款、信贷管理不到位
   合计占可归类处罚的 **78.7%**。
2. **大行与中小银行的违规结构不同**：大行"贷款三查不到位"占其自身处罚的 31%–34%，
   中小银行约 26%；但农村中小银行/村镇银行的**掩盖不良（五级分类不实）占 4%–5%**、
   **关联交易占 4%–5%**，国有大行仅 1% 与 0%。前者是**执行**问题，后者是**治理**问题。
3. **损失分布厚尾**：GPD 形状参数 ξ≈0.66（尾指数 1.5），
   99.9% VaR 约为年度损失均值的数倍。
4. **违规密度与规模显著负相关**：城商行约 **1.43 张/百亿营收**，
   国有大行约 **0.10 张**；Spearman ρ=−0.73（p<0.0001），
   Mann-Whitney 检验 p=0.006。**而资本公式对此完全不敏感。**
5. **监管资本与实测损失量级悬殊**：27 家上市城商行/农商行操作风险资本合计约
   **912.7 亿元**（BIA），而同一组机构的 99.9% VaR 约 **10.1 亿元**，
   仅占资本的 **1.1%**。这不是"资本充足"的证据，而是说明
   **罚款只捕捉到监管可见损失的下界**。
6. **违约识别的方法阶梯真实存在**：Altman Z' 直接照搬 AUC=0.66 →
   WOE 评分卡 0.84 → GBDT 0.90（按年份分组交叉验证，均值 0.82）。

## 三、数据

### 3.1 数据来源

| 项 | 内容 |
|---|---|
| 来源 | 国家金融监督管理总局 → 政务信息 → 行政处罚 |
| 接口 | `http://www.nfra.gov.cn/cbircweb/DocInfo/SelectDocByItemIdAndChild`（目录）<br>`http://www.nfra.gov.cn/cbircweb/DocInfo/SelectByDocId`（正文 `docClob`） |
| 栏目 | 总局机关 661 期 / 派出机构 29,198 期（2022-01 起） |
| 企业财务 | 东方财富 F10 主要财务指标（新三板/北交所 679 家，2020–2025） |
| 银行营收 | 东方财富 RPT_LICO_FN_CPD（42 家上市银行近三年营业总收入） |

**为什么必须用"派出机构"**：中小企业主要由地市监管分局监管。
只抓总局本级会得到 661 期、其中银行类仅 47 条 —— 会完全错失研究对象。

### 3.2 已修正的四类系统性数据错误

| # | 问题 | 后果 | 处理 |
|---|---|---|---|
| 1 | HTML 表格 `rowspan` 合并单元格，后续行省略被合并列 | 整行错位，违法事实串成处罚机关 | `table_to_grid()` 按合并关系展开成二维网格（记录数 +39%） |
| 2 | 表头"作出决定机关"被关键词"决定"抢先匹配 | 处罚机关字段全空 | 调整匹配优先级，机关优先于决定 |
| 3 | "罚没合计 + 分项罚款 + 分项没收"三处累加 | 金额虚高约 10 倍 | 合计口径优先，无合计才分项求和 |
| 4 | 信息公开表是"字段名横向合并 3 列 + 值在末列" | 标签被当成值，事实字段全是"主要违法违规事实（案由）" | `kv_bucket()` 按语义分槽，文号/日期/机关互斥 |

## 五、必须写进汇报/论文的局限

| 局限 | 说明 | 对结论的影响 |
|---|---|---|
| 罚款 ≠ 真实损失 | 不含声誉损失、拨备、整改成本 | LDA 结果是**下界**，方向偏保守 |
| 监管发现偏差 | 罚单密度反映监管关注度 | 不能用事件数直接推断真实风险分布 |
| 只看公示案件 | 未公示/未处罚的违规不可观测 | 存在系统性漏报 |
| 企业样本为挂牌公司 | 新三板/北交所 ≠ 银行真实小微客群 | 模型需在银行内部数据上重估 |
| 标签是财务困境代理 | "下一年资不抵债或亏损"，非真实贷款违约 | AUC 只说明相对识别能力 |
| 刻意不用"连续两年亏损" | 会用到 t 年利润，与特征循环定义，AUC 虚高至 0.94 | 修正后 AUC=0.84，更可信 |
| BI 以营业总收入近似 | 严格口径为利息+服务+金融资产 | 资本要求略有高估 |
| 密度样本较小 | 法人层级匹配到 27 家上市银行、204 条事件 | 密度结论方向稳健，具体数值有抽样误差 |
